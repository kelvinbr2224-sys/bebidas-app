# 🍺 BebidasApp

App de delivery de bebidas local — projeto de estudo e portfólio.

## 🔗 Link do app
https://kelvinbr2224-sys.github.io/bebidas-app/

## 📱 Funcionalidades

### Para o cliente
- ✅ Cadastro e login com e-mail/senha
- ✅ Catálogo de bebidas (cervejas, vodkas, whiskys)
- ✅ Filtros por categoria
- ✅ Carrinho com controle de quantidade
- ✅ Checkout com endereço e forma de pagamento
- ✅ Histórico de pedidos com status em tempo real

### Para o dono da loja
- ✅ Cadastrar e excluir produtos
- ✅ Painel de pedidos com filtros por status
- ✅ Contadores visuais (pendentes, aceitos, em entrega, entregues)
- ✅ Alterar status: aceitar → preparar → sair para entrega → entregue

## 🛠️ Tecnologias

- **HTML5** + **CSS3** + **JavaScript puro**
- **Firebase** (Authentication + Firestore)
- **GitHub Pages** (hospedagem)
